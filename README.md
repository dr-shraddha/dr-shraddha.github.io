## GitHub Pages

1. Create a GitHub repository.
2. Upload:
   - index.html
   - styles.css
   - script.js
   - README.md
3. Open:

Repository → Settings → Pages

4. Under "Build and deployment":

Source: Deploy from a branch

5. Select:

Branch: main  
Folder: / (root)

6. Save.

GitHub will provide the website URL.
